# Static asset folders

This directory contains files shipped with the frontend. Public URLs start with `/assets/`.

- `brand/` — logos and favicon artwork
- `images/banners/` — page and destination banner artwork
- `images/study-destinations/` — country study cards
- `images/goals/` — Home goal card artwork
- `images/study-abroad/` — general student imagery
- `media/logos/` — press and media logos
- `media/press/` — press images
- `media/reviews/` — office and reception photos
- `media/video-thumbnails/youtube/` — YouTube preview images
- `awards/` and `awards/events/` — award artwork and event banners
- `team/` — bundled team portraits

Images uploaded through the admin panel are stored by the backend under `Backend/uploads/`; see that folder's README for its categories.
